# VLG Code — AI Systems & Digital Engineering

Одностраничный сайт-визитка **VLG Code** в футуристическом HUD-стиле: интерактивное 3D-ядро на Canvas, анимированный «кодовый дождь», панели-разделы и галерея визуальных кейсов.

## Структура

- `index.html` — весь сайт (разметка, стили, логика в одном файле)
- `galary/` — изображения галереи (WebP)
- `fon/` — фоновое изображение (WebP)

## Хостинг

Сайт публикуется через **GitHub Pages** (ветка `main`, корень репозитория).
